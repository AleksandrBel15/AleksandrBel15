## 🚀 Featured Projects

### 📋 Offline-First Task Manager

A PWA task management application built around **offline-first architecture, local persistence, and complex task logic**.

The project focuses on building a reliable task management system that remains functional without a constant network connection.

**Highlights:**

* Offline-first application architecture
* IndexedDB local persistence
* Redux Toolkit state management
* Client-side data synchronization
* Recurring task system
* Recurring series creation, editing, and deletion
* Removing individual tasks from recurring series
* Advanced task sorting and filtering
* Active / completed task management
* PWA capabilities
* Complex asynchronous state handling

**Stack:**

`React` · `TypeScript` · `Redux Toolkit` · `IndexedDB` · `PWA`
